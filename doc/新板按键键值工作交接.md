# 新板按键键值工作交接

> 创建：2026-11-17
> 用途：记录新板（29 键）按键键值体系的改动，供负责**两头红外键值**（机顶盒/电视各一套）的同学接手。
> **后续与按键键值相关的所有改动，请追加记录到文末"变更记录"一节。**

## 1. 产品定位（已确认）

- BLE 仅与**机顶盒**配对；机顶盒 = 蓝牙 HID + 红外歌华 RC6 双通道，电视机 = 纯红外 NEC（0x51/0x53 用户码）。
- 通过"直播业务/电视机业务"两个按键切换控制目标（模式切换）。
- 旧键 HID 值保持不变（三处歌华私有：电视机业务 0x55、回看 0x41、机顶盒电源 0x0C）；新键按 GY/T 407-2024 表B.1；"点播"键暂借"设置"键值（HID 0xEB、红外 0x8D）。
- 学习键 4 个：电视机电源(1)、回看(11)、点播(14)、电视机业务(23)。

## 2. 键号体系（本轮改动核心）

**按键编号已切换为 SDK 44 键编号 KEY_n**（keyscan_map 下标，与硬件 KEYDATA 寄存器位一一对应）。29 个实体键的完整对照：

| 功能 | KEY_n | 线对 | HID (usage) | 歌华RC6 | NEC(电视) |
|---|---|---|---|---|---|
| 电视机电源(右) | 1 | PA1-PA0 | -（IR-only，不发HID） | - | 0xDC |
| 机顶盒电源(左) | 2 | PA0-PA2 | 0x66（电源HID身份） | 0x0C | 0xDC |
| 确定 | 3 | PA1-PA2 | 0x28 | 0x5C | 0xCE |
| 频道- | 4 | PA0-PA3 | 0x4E | 0x21 | 0x86 |
| 上 | 5 | PA1-PA3 | 0x52 | 0x58 | 0xCA |
| 下 | 6 | PA2-PA3 | 0x51 | 0x59 | 0xD2 |
| 音量- | 7 | PA0-PA6 | 0xEA (consumer) | 0x11 | 0x81 |
| 左 | 8 | PA1-PA6 | 0x50 | 0x5A | 0x99 |
| 右 | 9 | PA2-PA6 | 0x4F | 0x5B | 0xC1 |
| 音量+ | 10 | PA3-PA6 | 0xE9 (consumer) | 0x10 | 0x80 |
| 回看 | 11 | PA0-PB10 | 0x41 | - | 0x37 |
| 直播业务 | 12 | PA1-PB10 | 0x3D | - | 0x3D |
| 主页 | 13 | PA2-PB10 | 0x4A | 0x82 | 0x88 |
| 点播(借设置码) | 14 | PA3-PB10 | 0xEB | - | 0x8D |
| 数字1 | 15 | PA6-PB10 | 0x1E | - | 0x92 |
| 语音 | 16 | PA0-PB8 | 0x3E | - | 0xE5 |
| 频道+ | 17 | PA1-PB8 | 0x4B | 0x20 | 0x85 |
| 菜单 | 18 | PA2-PB8 | 0x65 | 0x54 | 0x82 |
| 返回 | 19 | PA3-PB8 | 0x29 | 0x0A | 0x95 |
| 数字2 | 20 | PA6-PB8 | 0x1F | - | 0x93 |
| 数字3 | 21 | PB8-PB10 | 0x20 | - | 0xCC |
| 数字4 | 22 | PA0-PB9 | 0x21 | - | 0x8E |
| 电视机业务 | 23 | PA1-PB9 | 0x55 | - | 0x88 |
| 数字5 | 24 | PA2-PB9 | 0x22 | - | 0x8F |
| 数字6 | 25 | PA3-PB9 | 0x23 | - | 0xC8 |
| 数字7 | 26 | PA6-PB9 | 0x24 | - | 0x8A |
| 数字8 | 27 | PB10-PB9 | 0x25 | - | 0x8B |
| 数字9 | 28 | PB8-PB9 | 0x26 | - | 0xC4 |
| 数字0(独立键) | 29 | PA0→GND | 0x27 | - | 0x87 |

说明：
- 歌华 RC6 列为 "-" 表示当前无码（不发红外）；**两头键值工作的重点之一就是补齐这些空位**（如果甲方给了歌华对应键值）。
- **电视机电源是 IR-only 键**：不发 HID、不报 RC/Tag10（task_keyscan.c 中对 TV_POWER 直接 return）；**机顶盒电源发电源 HID 0x66**（已移除旧的按键号重映射，HID 表 case 2 直接给 0x66），断开 BLE 时发 RC6 0x0C。
- 数字0 是**独立键**（KEYDATA0 bit0），按下期间矩阵区被屏蔽（硬件规则）。

## 4. 模式切换路由表（最终版，已实现 2026-11-17）

活跃设备状态：`mode ∈ {STB, TV}`，上电默认 STB，跨断连保持；直播业务 → STB，电视机业务 → TV（标准 5.1.1.3 + 脚注 c/d）。**本产品无电视焦点属性，活跃设备 = 焦点设备。**

| 键 | STB 模式 | TV 模式 | 依据 |
|---|---|---|---|
| 电视机电源(1) | NEC 0xDC / 学习波形（固定电视，IR-only） | 同左 | 分立电源键；电视仅红外 |
| 机顶盒电源(2) | HID 0x66 + Tag10 开机；断 BLE 时 RC6 0x0C | 同左（固定机顶盒） | 分立电源键 |
| 直播业务(12) | HID 0x3D | 先 NEC 0x3D → 切 STB → HID 0x3D | 标准脚注 c |
| 电视机业务(23) | 切 TV → NEC 0x88（**不发 HID**，电视目标键一律 IR-only） | NEC 0x88 | 标准脚注 d |
| 频道±(4,17)/回看(11) | HID + RC6（断 BLE 时） | 同左（**固定机顶盒，已按标准确认**） | 标准控制对象=机顶盒 |
| 音量±(7,10) | HID consumer（连 BLE 时）/ RC6 0x10,0x11（断 BLE 时） | NEC 0x80/0x81 | 标准控制对象=电视机或机顶盒（**跟随模式，已按产品确认**） |
| 主页(13)/菜单(18)/确定(3)/返回(19)/上下左右(5,6,8,9)/数字(15,20~29)/点播(14) | HID + RC6（断 BLE 时） | NEC / 学习波形（与蓝牙连接无关） | 标准活跃/焦点设备跟随 |
| 语音(16) | 固定机顶盒（HID+语音通道，BLE-only） | 同左 | 电视无语音能力 |

学习波形优先级：学习值 > 默认码（仅在学习键 1/11/14/23 上生效，且仅在红外通道路由时使用，不覆盖 HID）。

实现要点（task_keyscan.c）：
- 模式状态 `s_control_mode` + `task_keyscan_control_mode()` 查询接口；
- 新增 `ir_send_key_tv()`（ir_key_map.c）：电视红外通道，学习波形优先，否则 NEC 表；
- HID 释放门控 `s_key_hid_active`：电视模式路由的键未发 HID press，释放时不再补发无主释放；
- 长按 400ms 重复键集合 = {4,5,6,7,8,9,10,17} + 学习键。

## 5. 两头红外键值的接入方式（给接手同学）

1. **键号统一用 KEY_n（1~29）**，不要再用旧 18 键编号——上表是所有表共用的索引。
2. 补齐/修改键值时只改第 3 节列出的表，不要动 keyscan_map（那是硬件位表）。
3. 歌华 RC6 空位（"-"）若有甲方键值，填入 `codes[KEY_n]`；NEC 表如需换码直接改 `ir_default_cmd_table[KEY_n]`。
4. 改完跑主机回归：`python tools/test_ir.py`（11 组，含 RC6 512 码回环、NEC 表、TX 路由、学习策略）＋ `python tools/test_base_merge.py`（13 组）。
5. 上板验证：新板全键红外示波器/接收端验证 + 学习键重新学习（VERSION 升级后旧数据已作废）。
