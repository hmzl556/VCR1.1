## 一页速览

```
蓝牙芯片                                      4G 模组
   │ ① 抽 8 字节随机数 nonce                     │
   │ ──── AT+RCHS=0,0102030405060708 ────────► │ ② 用密钥算 XTEA(nonce)
   │ ◄──── +RCHS: 61AA3ADB1E6E9224 ─────────── │
   │            OK                             │
   │ ③ 自己也算一遍，比对                          │
   │    相同 → 放行 ✅        不同/超时 → 复位 ❌   │
```

- **算法**：XTEA，64-bit 分组 / 128-bit 密钥 / 32 cycles / 全大端，代码约 20 行
- **报文**：8 字节随机数 → 8 字节答案，全 ASCII 十六进制
- **另有** `AT+RCHS?` → 版本号 + 密钥指纹（KCV），用于产测核对两边密钥一致
- **代价**：单次 < 10 ms；冷启动多 2~3 s（等模组启动）；平时不给模组额外上电
- **失败**：3 次重试 → 复位 → 再失败则锁定（停广播/按键/红外，保留 BLE 升级可恢复）

## 当前决定（默认值，可调整）

| 事项 | 取值 |
|---|---|
| 失败处置 | 复位 1 次仍失败 → 锁定态 |
| 握手时机 | 冷启动强制 + 模组每次上电 + 运行中随机 2~10 min |
| 密钥粒度 | 按批次一把（`idx` 预留每台唯一） |
| 过渡开关 | 未出货，无存量负担 → 模组固件就绪后直接强制（`RCHS_ENFORCE=1`） |
