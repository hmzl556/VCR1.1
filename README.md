## 硬件与默认路由

PB4红外发射，PB5接收原始低有效载波。LED1红灯在PB3，LED2蓝灯在PB7。CAT1仍使用原工程PA4 TX、PA5 RX。

- 左侧实体KEY18（PB9—PA6）是机顶盒电源，默认歌华RC6系统码0x26、命令0x0C。原HID/RC/Tag10电源身份和回连唤醒行为保留。
- 右侧实体KEY1是电视机电源，短按松开后发一次，长按5秒进入学习时不先发电源码、不连发。已学习时发学习波形；未学习时保留原NEC用户码0x51/0x53、命令0xDC。
- 13个固定歌华RC6键禁止学习，历史学习值也不覆盖：确认5C、左5A、右5B、下59、主页82、返回0A、菜单54、频道+20、音量+10、频道-21、音量-11、上58、机顶盒电源0C。
- KEY2静音、KEY3电视业务、KEY17回看未学习时无默认红外码；BLE业务保留。KEY15语音仅用于蓝牙，不发红外。学习记录只在选择红外通道后使用，不覆盖蓝牙映射；KEY15语音禁止学习，旧语音学习记录忽略，连接时保留语音功能。
- 普通未学习键保留BLE优先、断开后红外；机顶盒电源连接BLE时只发HID，未连接时发歌华RC6；不再同时双发。
- 方向、音量、频道长按400ms后重复；学习后的KEY2/3/17也支持长按。其他固定键与电视电源不重复。

## 学习操作（LED1红灯）

1. 持续按右侧电视电源KEY1至少5秒，LED1红灯常亮后松开。
2. 短按目标键并松开。只允许KEY1、KEY2、KEY3、KEY17；按其余14键不会改变目标或发射。
3. LED1红灯闪烁时，把原遥控器发射头对准本机PB5接收位置，间距约2～5cm，等待约0.2秒后按原遥控器对应键；可保持1～2秒以供失败后自动重试。
4. 成功保存：LED1红灯慢闪3次后常亮；保存失败：LED1红灯快闪5次后常亮，旧学习码保留。坏帧在15秒接收窗口内自动重试，日志为RX retry，不把坏帧报告为保存成功。
5. 常亮后可选择下一目标。15秒无本机按键操作退出，LED1红灯熄灭。退出后短按/长按刚学习的键验证，再做实体复位和断电重启验证。

学习保存载波周期和最多255段MARK/SPACE。约20～60kHz、单段80～65535us、单帧总长不超过250ms；20ms无载波分帧。支持NEC、8010前缀歌华RC6及范围内未知协议的原始波形；不保证空调多帧或特殊协议。

歌华RC6通过结构校验后按36kHz、444us标准半位重建，每次新按下翻转toggle、同次长按保持。NEC短按回放完整波形，长按使用专用重复帧并保留所学载波频率；未知协议重复完整帧。帧起点间隔至少108ms，长帧额外保留至少20ms空隙。

## 组合键与恢复出厂

- 音量+和主页切机顶盒用户码：已停用，歌华系统码固定0x26。
- 音量+和返回（KEY12+KEY9）长按3秒：切电视机NEC用户码0x51/0x53，默认慢闪2次、备用快闪3次。两灯指示；不改已学习波形。重启回默认0x51。原“音量+和菜单”已取消。
- 音量-和电视（KEY14+KEY3）：仅发送电视配对NEC命令7D，不影响机顶盒绑定；音量-和左（KEY14+KEY5）：机顶盒配对歌华RC6命令AD，先完成机顶盒清绑定Flash写入和配对广播设置，再发红外。原“音量-和静音”已取消。
- 电视和返回（KEY3+KEY9）：因无独立电视BLE上下文，暂不执行电视解配，不影响机顶盒；返回和左（KEY9+KEY5）：机顶盒解配。原“返回和静音”已取消。
- 主页和音量-长按3秒，松开后10秒内按确认：先持久化清学习表、恢复用户码，再清原绑定；持久化失败不报告复位成功。

## 并行运行与存储

正式APP采用TIM3_CH2每个下降沿硬件捕获，CH1比较合并100us载波间隙。中断只收集时间戳和载波周期直方图，任务校验、重试及保存；没有参考独立工程的270ms集中轮询或暂停按键扫描。捕获溢出、坏RC6结构、异常频率/时长均拒绝保存。实际BLE/串口负载下的采集能力仍须上板验证。

PB4歌华RC6及原始回放使用TIM3_CH1载波、TIM6分段中断；保留NEC IRC驱动和禁用IRQ31的既有修复。发送不忙等，接收与发送互斥，迟到中断及发送超时停止当前帧。波形缓冲按需分配，分配失败返回失败，ISR内不分配或释放堆内存。空闲时启动发送失败会丢弃该帧并打印诊断，避免坏记录或内存不足永久堵住队列。

原始学习区兼容参考工程18槽位格式：A为0x0106B000～0x0106DFFF，B为0x0106E000～0x01070FFF，各12KB。CRC校验、序号选新、写另一区、分块读回后最后提交magic。读取每次最多256字节，写入不跨256字节页。RAM只缓存4键有效位及RC6元数据，按键入队不读Flash，实际发射空闲后才读取波形，避免Flash读临界区破坏当前发射时序。

旧NEC两个区及其兼容读取/迁移代码已删除，波形区紧接云配置区，释放出的8KB已用于将后续分区整体前移。0x01071000～0x0107FFFF为当前未分配区，共60KB。新波形数据格式仍为版本1、18槽位，但位置与旧固件和独立参考工程不同；用户已确认不迁移，更新后重新学习。此版不会在启动时自动擦学习区，但旧地址数据不会被加载。不要使用整片擦除来保留后续新学习的数据。

- 云策略：0x0106A000～0x0106AFFF，4KB。
- 波形A：0x0106B000～0x0106DFFF，12KB。
- 波形B：0x0106E000～0x01070FFF，12KB。
- 未分配：0x01071000～0x0107FFFF，60KB。


OTA期间不学习或更新存储；进入OTA取消学习。CAT1忙时保留捕获结果，待串口事务空闲再保存；等待期间继续任务调度。Flash访问均在任务上下文，红外活动阻止休眠。Bootloader及APP/OTA/红外存储布局保留。CAT1上报字段已按最新APP基础更新。

### 已修复的运行问题

- 系统8ms定时器被OTA循环重复创建；SDK有效句柄0被当成无效值；取消后旧回调可能重装定时器。现为单一受管定时器，按代次拒绝旧回调，表满时主循环重试。休眠闹钟也处理句柄0和过期回调，待机/休眠循环补充喂狗。
- 同时按组合键没有单键编号，可能不能退出待机/休眠；入睡前已有按键也可能再进入睡眠。现按原始矩阵活动判断，保留休眠断连清理期间的唤醒按键。
- 32位毫秒回绕被误判为计时下溢。空闲判断改为无符号时间差，避免回绕后错误重置空闲计时。
- CAT1的启动延迟、重试间隙和待上传业务未被AT busy覆盖，可能被PM中断或在BLE活跃时饿死。增加完整业务保护、约120秒建链截止和失败清理；模组断电后仍检查BLE半包超时，汇聚超时使用统一单调时钟。短心跳周期不再反复重启尚在建链的模组。
- 满上报队列在组帧时覆盖尚未出队的旧数据，过滤后尾索引也可能等于容量。现独立临时组帧、环形索引取模、原位保持FIFO；减少原先约1.2KB的队列整理栈拷贝。
- HID延后区只能保留一个按下，UART事务期间多次按键可能被覆盖。改为16事件FIFO；溢出明确记录诊断，恢复时先释放两类HID报告，避免卡键。蓝牙断连清空旧事件，组合键接管取消待发按下。
- BLE失败连接被标记成已连接；CCCD重试定时器跨连接残留。增加成功检查、连接代次校验及断连清理；不再通过已断开的peer更新参数。绑定Flash读失败、身份地址获取失败时不恢复/保存伪记录。唤醒地址读缓冲按SDK的4字节读取粒度预留。
- 已学习语音键回放启动失败时可能转为语音；断开蓝牙仍可能开启麦克风。现按学习策略及连接状态判定，语音控制同时检查OTA/IR互斥；STOP优先清理命令队列，语音活跃时不进入低功耗。语音停止只屏蔽DMA_CH1，不关闭共享NVIC入口。
- Tag11部分字段先更新、后发现坏字段时未回滚。现完整校验后提交采集/上报/心跳字段；OTA版本与包数须成对，纯OTA控制字段也可正常识别。
- 560字节明文经PKCS填充需要576字节密文，完整6868帧为597字节，原592字节容量不足。改为608字节并同步串口行/接收环容量，增加编译期边界检查。
- OTA短帧在验证固定头部长度前读取字段；BCD长度没有检查非法半字节。已补充边界校验、最大包数及程序长度/包数一致性校验。
- OTA断点反复覆盖同一NOR地址，无法可靠保存后续序号。改为现有OTA配置扇区+0x200起的32字节追加记录，CRC及最后提交标志验证；每8片及暂停时保存。断点满时安全清理该配置扇区，掉电可能退回全新下载，但不会把未完成镜像提交给Bootloader。旧单条OTA断点不迁移；学习分区和Bootloader参数/marker位置不变。
- OTA写片增加读回；整包校验遇到Flash读失败立即失败；升级参数读回确认后最后写安装标志。擦除APP2时每完成一个扇区喂狗，避免大镜像预擦除期间误复位。
- OTA会话明确暂停红外及学习、保持已连接HID，避免Flash关中断破坏IR时序。失败退出时恢复普通广播路径。这一升级期间产品行为列入待确认文档。
- 学习表启动读取/内存分配失败时禁止覆盖旧表；清表前重新确认分区及序号，避免未看见的新分区在重启后恢复旧学习值。

### 2026-10-23：重连后语音通道恢复检查
