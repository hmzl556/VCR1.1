20.3. IRC 功能模块 
红外控制器由输入用户接口、载波发生器、调制器组成，框图如下： 
 
图 20-1 IRC 功能框图 
 输入用户接口 
输入用户接口模块由APB 寄出去接口、两个FIFO 和消息解码引擎组成，该子模块负责系统的
配置以及编码字的存储和解码，这些编码字将驻留在代码的FIFO 中。 
Repeat FIFO 可以用来加载特殊的命令，例如长按键时，发送指定间隔相同的重复指令。 
Code FIFO 的输出被消息解码引擎解码，并以命令的形式送给下一个子模块调制器。
