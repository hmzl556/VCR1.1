1. 功能描述
     1. 旋转编码器例程

2. 使用环境
    软件开发环境：KEIL MDK‑ARM V5.30.0.0
    硬件环境：基于BR1601 DK开发板开发

3. 使用说明
    系统配置：
         1. 时钟源：
            HSI=64M，AHB=64M，APB1=32M，APB2=64M，TIM1时钟=64M，TIM3时钟=64M
         2. 中断：
                     开启TIM1更新中断，优先级3
         3. 端口配置：
                     PB0 为编码器A相引脚 WHEEL_A_PIN
                     PB9 为编码器B相引脚 WHEEL_B_PIN
                     PB1 为日志打印端口
         4. 定时器配置：
                     TIM1配置为编码器接口模式
                     TIM1开启周期中断

     操作步骤：
         1. 编译完成后，开启调试模式或将程序烧录至DK开发板，打开串口助手
         2. 将编码器硬件连接至对应IO引脚
         3. 程序运行后，拨动旋转编码器，通过串口助手查看输出结果

4. 注意事项
    需要在旋转编码器输入引脚增加滤波电容。
