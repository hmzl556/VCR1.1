1. 功能描述
     1. TIM1完成一个周期后，同时修改周期与占空比

2. 使用环境
    软件开发环境：KEIL MDK‑ARM V5.30.0.0
    硬件环境：基于BR1601 DK开发板开发

3. 使用说明
    系统配置：
        1. 时钟源：
            HSI=64M，AHB=64M，APB1=32M，APB2=64M，TIM1时钟=64M
        2. 端口配置：
                     PA8 配置为TIM1 CH1输出
        3. 定时器配置：
            TIM1 CH1输出，周期触发DMA突发传输，加载AR、REPCNT、CCDAT1寄存器，修改占空比、周期以及重复计数器
        4. DMA配置：
                     DMA1_CH5通道普通模式，将3个半字SRC_Buffer[3]变量传输至TIM1 DMA寄存器
    操作步骤：
        1. 编译后打开调试模式，使用示波器或逻辑分析仪观测TIM1 CH1波形
        2. TIM1第一个周期结束后，后续波形为DMA传输更新周期和占空比后的输出波形

4. 注意事项
    无
