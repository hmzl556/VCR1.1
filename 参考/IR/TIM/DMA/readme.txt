1. 功能描述
    1. TIM1 CH1、CH1N互补信号每6个周期改变一次占空比

2. 使用环境
    软件开发环境：KEIL MDK‑ARM V5.30.0.0
    硬件环境：基于BR1601 DK开发板开发

3. 使用说明
    系统配置：
        1. 时钟源：
            HSI=64M，AHB=64M，APB1=32M，APB2=64M，TIM1时钟=64M
        2. 端口配置：
            PB8 配置为TIM1 CH1输出
            PB12配置为TIM1 CH1N输出
        3. 定时器配置：
            TIM1 CH1、CH1N互补输出，每6个周期触发一次DMA传输
        4. DMA配置：
            DMA1_CH5通道循环模式，将3个半字SRC_Buffer[3]变量传输至TIM1 CCDAT3寄存器

     操作步骤：
         1. 编译后开启调试模式，使用示波器或逻辑分析仪观测TIM1 CH1、CH1N波形
         2. TIM1每6个周期切换一次CH1与CH1N占空比，循环往复

4. 注意事项
    无
