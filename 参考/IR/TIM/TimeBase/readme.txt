1. 功能描述
     1. TIM3利用CH1、CH2、CH3、CH4比较值产生定时中断，并翻转IO电平

2. 使用环境
    软件开发环境：KEIL MDK‑ARM V5.30.0.0
    硬件环境：基于BR1601 DK开发板开发

3. 使用说明
    系统配置：
        1. 时钟源：
            HSI=64M，AHB=64M，APB1=32M，APB2=64M，TIM1时钟=64M，TIM3时钟=64M
         2. 中断：
             开启TIM3比较中断，优先级1
         3. 端口配置：
                     PB6 配置为IO输出
                     PB7 配置为IO输出
                     PB11 配置为IO输出
                     PB12 配置为IO输出
         4. 定时器配置：
                     TIM3输出冻结模式，开启CH1、CH2、CH3、CH4比较值中断

     操作步骤：
         1. 编译后打开调试模式，使用示波器或逻辑分析仪观测PB6、PB7、PB11、PB12引脚波形
         2. 程序运行后，对应通道计数到达比较值，累加比较值同时翻转对应IO口电平

4. 注意事项
    开发板PB6、PB7默认跳线帽连接DAPLink虚拟串口。若项目中PB6、PB7不作为串口，用作其他功能，必须拔掉串口跳线帽。
