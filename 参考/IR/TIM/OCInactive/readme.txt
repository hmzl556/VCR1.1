功能描述
     1. TIM3 CH1、CH2、CH3、CH4计数到比较值后，对应将PB4、PB5、PB6、PB7引脚IO电平拉低。

2. 使用环境
    软件开发环境：KEIL MDK‑ARM V5.30.0.0
    硬件环境：基于BR1601 DK开发板开发

3. 使用说明
    系统配置：
        1. 时钟源：
            HSI=64M，AHB=64M，APB1=32M，APB2=64M，TIM3时钟=64M
         2. 中断：
                    开启TIM3比较中断，子优先级1
         3. 端口配置：
                     PB4 配置为IO输出
                     PB5 配置为IO输出
                     PB6 配置为IO输出
                     PB7 配置为IO输出
         4. 定时器配置：
                    TIM3配置CH1、CH2、CH3、CH4比较值，并开启比较中断

     操作步骤：
         1. 编译后打开调试模式，使用示波器或逻辑分析仪观测PA6、PA7、PA8、PA9波形
         2. 定时器计数达到CC1、CC2、CC3、CC4后，对应将PA6、PA7、PA8、PA9IO电平拉低

4. 注意事项
    开发板PB6、PB7默认跳线帽连接DAPLink虚拟串口。若项目中PB6、PB7不作为串口，用作其他功能，必须拔掉串口跳线帽。
