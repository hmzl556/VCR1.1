# 1. 功能说明
1. ADC对PB8引脚和PB10引脚的模拟电压进行采样转换。
2. 采用软件单次触发，单次采集。

# 2. 使用环境
软件开发环境：KEIL MDK-ARM V5.30.0.0
硬件环境：基于BR1601 DK开发板开发

# 3. 使用说明
系统配置：
1. 时钟源：
HSE=32M，HSI=64M，AHB=64M，APB1=32M，APB2=64M，ADC时钟=HSE/8
2. 端口配置：
PB8设为模拟功能，ADC转换通道3（高压通道）
PB10设为模拟功能，ADC转换通道1（低压通道）
3. ADC：
ADC配置：连续转换，软件触发，10位数据，通道3转换结果为PB8模拟电压数据，通道1转换结果为PB10模拟电压数据
4. 日志打印：演示板PB6（发送端），波特率115200，8位数据位，1位停止位，无校验位，无硬件流控

使用方法：
1. 编译后下载程序，复位运行，在日志中查看转换结果。
2. 改变PA1引脚电压，可观察到转换结果变量同步变化。

# 4. 注意事项
请确保J15接左侧、J16接右侧，使IO口连接至弹簧顶针而非晶振。
